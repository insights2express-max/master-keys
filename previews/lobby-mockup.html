What changes

splash screen → Lobby → Setup screen → game screen

  1. 1The Lobby holds only what every game shares: you, your coins, sound, Game History (all games, with a tab per game, as now) and How To Play for the suite.
  2. 2⚙ Master Keys settings (new): Screen (Auto / Light / Dark / Night) moves here from CrossKeys Options, because it changes every game.
  3. 3Equal game cards: icon, one-line description and your record. LockWord is the same size as CrossKeys. Tapping the card opens its Setup screen.
  4. 4▶ Play starts at once with your last settings, so CrossKeys is still one tap away. When a game is unfinished, the card says so and ▶ Play becomes ▶ Resume.
  5. 5⚙ Setup opens the game's own Setup screen.
  6. 6“More games on the way”: an optional placeholder for the next game from New Games research. Your call (RFI).
  7. 7CrossKeys Setup: Bot, Challenge Level, Grid Size and Options move here from today's home screen, unchanged (Grid Colors and the defaults buttons included).
  8. 8A stats row for CrossKeys, built like LockWord's.
  9. 9☰ goes back to the Lobby from every Setup screen; in a game, ☰'s menu gets “Back to the Lobby”. The ? on a Setup screen opens that game's own How To Play.

Unchanged: your saves, coins, settings, History and Lexicon edits. Only where things sit on screen changes. Numbers, names and records here are made up.
