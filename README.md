# Clue Duel

A head-to-head crossword tile game: you and a computer rival fill the same arrow-word grid with letter tiles.

**Play:** https://insights2express-max.github.io/clue-duel/

It is an installable web app (PWA). After the first visit it plays fully offline.

**Word list:** https://insights2express-max.github.io/clue-duel/lexicon.html (searchable, sortable)
- **Android (Opera or Chrome):** open the link, then use the menu → **Install app** or **Add to Home screen**.
- **iPad / iPhone (Safari):** open the link, then tap Share → **Add to Home Screen**.
- **Windows (Edge or Chrome):** open the link and click the install icon in the address bar.
