# Master Keys

Two word games in one offline web app (formerly called Clue Duel):
- **CrossKeys** (formerly Clue Duel): you and a computer rival (the Bot) fill the same arrow-word grid with letter tiles.
- **LockWord** (formerly Word Vault): guess the hidden word in a set number of tries.

**Play:** https://insights2express-max.github.io/master-keys/

It is an installable web app (PWA). After the first visit it plays fully offline.

**Word list:** https://insights2express-max.github.io/master-keys/lexicon.html (searchable, sortable)
- **Android (Opera or Chrome):** open the link, then use the menu → **Install app** or **Add to Home screen**.
- **iPad / iPhone (Safari):** open the link, then tap Share → **Add to Home Screen**.
- **Windows (Edge, Chrome or Opera):** open the link and click the install icon in the address bar.
